# 手工算例（验收对照基准）

所有金额使用 `BigDecimal`（PostgreSQL `NUMERIC`）十进制定点：电量 9 位小数、未舍入金额 12 位、应收金额 2 位，
舍入一律 **HALF_UP（四舍五入到分）**。园区固定时区 **Asia/Shanghai（+08:00，无夏令时）**。

## 0. 计费口径

1. **读数模型**：读数为单调不减的累计表底数。相邻读数间隔 > 正常抄表节奏 × 1.5 视为**缺失**：
   该区间电量**不计费、绝不当零**，在账单中显式登记缺口（`bill_gap`）。表码倒走直接报错。
2. **账期**：本地自然月，半开区间 `[月初 00:00, 次月1日 00:00)`。区间与账期取交集；
   为处理跨月边界，读数取账期前最后一条与账期后第一条参与切分。
3. **切分**：相邻读数区间依次按 **费率版本生效边界 → 本地午夜 → 尖峰平谷时段边界** 切分。
   片段电量 = 区间电量 ×（片段秒数 / 区间总秒数），即区间内线性分摊。
4. **跨午夜时段**：时段按本地墙钟分钟定义，`startMin > endMin` 表示跨午夜（谷段 22:00–次日06:00）。
5. **月中调价**：费率版本为半开生效区间 `[from, to)`，切换瞬间两侧分别适用旧/新版本；
   费率覆盖必须连续，出现缺口或重叠直接报错。
6. **月度阶梯**：片段按时间先后进入“片段当时生效版本”的档位；月累计电量全局连续；
   跨档瞬间把同一片段电量拆入两档；档位区间为 `[下界, 上界)`，**恰好落在边界上的累计值仍属上一档**。
7. **舍入**：每个费用项保留未舍入金额并各自 HALF_UP 到分；应收金额 = 未舍入合计一次 HALF_UP 到分；
   `舍入差额 = 应收 − 分项舍入之和`，单列一行，保证「分项金额 + 舍入差额 ≡ 应收」。
8. **账单冻结**：确认时把全部计算依据（表计、窗口、费率版本/时段/阶梯、日历、参与读数、规则、结果）
   序列化为 JSON 快照并计算 SHA-256 指纹，随账单持久化。之后改价或补读数**不影响**历史账单。

## 1. 费率（样本）

| 版本 | 生效区间（本地） | 尖 20:00-22:00 | 平 06:00-20:00 | 谷 22:00-次日06:00 | 阶梯 |
|---|---|---|---|---|---|
| V2025-STD | 2025-01-01 → 2026-03-01 | 1.20 | 0.70 | 0.35 | 一档 ≤1000，加价 0（样本月不越档） |
| V2026-03-PREMIUM | 2026-03-01 → 2026-03-15 | 1.3025 | 0.753 | 0.40 | [0,50) 加价 0；[50,∞) 加价 0.10 |
| V2026-03MID-ADJ | 2026-03-15 → 开放 | 1.35 | 0.78 | 0.42 | [0,50) 加价 0；[50,∞) 加价 0.12 |

尖峰平谷定义中谷段 `startMin=1320 > endMin=360`，为**跨午夜**时段。
样本日期在费率日历中全部显式标记为 `WORKDAY`（日历权威，覆盖周末回退规则）。

## 2. M-001（2h 抄表 / 跨午夜 / 跨月调价 / 缺失读数）

恒定 3kWh/h，读数为偶数小时对齐；**漏抄 02-28 09:00 一点**。
缺失阈值 = 7200s × 1.5 = 10800s（3h）。序列（节选）：

```
02-27 21:00=0  23:00=6
02-28 01:00=12 03:00=18 05:00=24 07:00=30 | 09:00 漏抄 | 11:00=42
       13:00=48 15:00=54 17:00=60 19:00=66 21:00=72 23:00=78
03-01 01:00=84 03:00=90 05:00=96
```

### 缺失（不当零）

- `02-28 07:00 → 11:00` 间隔 4h > 3h：登记 `MISSING_READING`，
  但注意**区间电量仍为 12kWh**（30→42），只是因无法确定期间分布而**整体不计费**。
- 全月视图下另有 `BEFORE_FIRST`（首条 02-27 21:00 之前）与 3 月 `AFTER_LAST`（末条 03-01 05:00 之后）。

### 跨午夜 + 跨月调价（同一读数区间同时跨越两者）

读数区间 `02-28 23:00(78) → 03-01 01:00(84)`，区间电量 6kWh，2h：

| 片段 | 时段 | 费率版本 | 单价 | 电量 |
|---|---|---|---|---|
| [02-28 23:00, 03-01 00:00) | 谷 | **V2025-STD（旧价）** | 0.35 | 3 |
| [03-01 00:00, 01:00) | 谷 | **V2026-03-PREMIUM（新价）** | 0.40 | 3 |

切分在午夜（= 调价时刻）处一次完成，两个片段各归各账期、各按其价。

### 2026-02 账期金额（引擎实算并由单测锁定）

| 时段 | 电量 | 单价 | 金额 |
|---|---|---|---|
| 谷 | 30 | 0.35 | 10.50 |
| 平 | 30 | 0.70 | 21.00 |
| 尖 | 9 | 1.20 | 10.80 |
| **合计（计费 69kWh，另有 12kWh 缺失排除）** | | | **42.30** |

### 2026-03 账期金额（样本前段，全部谷段新价）

窗口 [03-01 00:00, 04-01 00:00) 内有效片段：00-01、01-03、03-05 共 15kWh 谷段 × 0.40 = **6.00 元**；
不足 50kWh 无阶梯附加；账期末登记 `AFTER_LAST`。

## 3. M-002 / 2026-03（月中调价 + 恰好越过阶梯边界）

90 分钟一条，03-14 00:00=0 起每条 +3，至 03-15 03:00=54，共 54kWh（18 个区间）。
档位 [0,50) 一档、[50,∞) 二档。**月累计到 03-15 01:30 恰好 = 50，仍属一档；随后电量进入二档。**

### 时段拆分（每区间 3kWh，按版本/午夜/时段边界切）

v2 区间（03-14 00:00 → 03-15 00:00，共 16 个 90 分钟区间 = 48kWh）：

- **谷 16kWh**：00:00-06:00 四个完整区间 = 12；
  区间[21:00,22:30) 在 22:00 切分，[22:00,22:30) 30min 分摊 3×(30/90)=1；
  区间[22:30,24:00) 全在谷段 = 3。
- **尖 4kWh**：区间[19:30,21:00) 在 20:00 切分，[20:00,21:00) 60min 分摊 3×(60/90)=2；
  区间[21:00,22:30) 中 [21:00,22:00) 60min 分摊 2。
- **平 28kWh**：其余落在 06:00-20:00 的区间合计（19:30 起点区间贡献 [19:30,20:00)=1）。

v3 区间（03-15 00:00 → 03:00，2 个区间，全部谷段）：00:00→01:30 = 3，01:30→03:00 = 3，**谷 6kWh**。

合计 16+4+28+6 = 54kWh。

### 阶梯（按时间累计；档位 [下界,上界)，边界 50 本身属一档）

| 片段落点 | 落入前月累计 | 档位 | 电量 | 版本加价 |
|---|---|---|---|---|
| 03-15 00:00 前全部（v2） | 0 → 48 | 一档 | 48 | 0 |
| v3 [00:00,01:30) 谷段（3kWh） | 48 | 48→50 属一档；50→51 属二档 | 2（一档）+ **1（二档）** | 0 / +0.12 |
| v3 [01:30,03:00) 谷段 | 51 | 二档 | **3（二档）** | +0.12 |

→ **一档 50kWh（无加价）、二档 4kWh（v3，+0.12）。**

### 金额

| 项 | 计算 | 未舍入 | 分项舍入 |
|---|---|---|---|
| v2 谷能量 | 16 × 0.40 | 5.800 | 5.80 |
| v2 尖能量 | 4 × 1.3025 | 5.210 | 5.21 |
| v2 平能量 | 28 × 0.753 | 21.084 | 21.08 |
| v3 谷能量 | 6 × 0.42 | 2.520 | 2.52 |
| 二档阶梯附加（v3） | 4 × 0.12 | 0.480 | 0.48 |

- 未舍入合计 = 5.800+5.210+21.084+2.520+0.480 = **35.694 → 应收 35.69**
- 分项舍入之和 = 5.80+5.21+21.08+2.52+0.48 = **35.69**
- **舍入差额 0.00；应收 35.69 元。**

## 4. 纯舍入差额最小算例（自动化测试）

两个时段单价均为 1.005，各 1kWh：未舍入 2.010 → 应收 2.01；分项各 1.01，和 2.02；差额 **−0.01**。
界面选中「舍入差额」行可看到完整恒等式与每一项的未舍入值。

## 5. 缺失绝不置零

整月仅有首尾两条读数且间隔超阈值：计费电量 0、金额 0.00，但**不产生任何片段**，
只登记 `MISSING_READING`（以及 `AFTER_LAST`），曲线页以红色虚线 + 阴影标示，账单页明示缺口。

## 6. 失败口径（自动化测试覆盖）

- 表码倒走 → 直接抛错，拒绝计费；
- 费率版本在账期内出现覆盖缺口（如新版本 03-10 终止后无续接）→ 直接抛错；
- 同一费率版本时段定义重叠或缺分钟 → 启动/计费时校验抛错。
